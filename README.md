## 📂 Project Structure & Machine Learning Implementation

This repository contains a full-stack application. **For the Amazon ML Summer School review, please navigate directly to the `python-backend` directory.**

- 📁 `python-backend/` - **[⭐ Core ML Work]** Contains the Student Dropout Prediction model, synthetic data generation scripts, training notebooks, and evaluation metrics.
- 📁 `csv/` - Contains the synthetic datasets (Student Details, Fee Status, Grades) used for model training.
- 📁 `app/` & `public/` - Frontend user interface.
- 📁 `prisma/` & `qr-backend/` - Database ORM and secondary backend services.
